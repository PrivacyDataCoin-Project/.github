# Privacy Data Coin

Privacy Data Coin is a confidential blockchain. A wallet transfer hides the sender, the receiver, the amount, and the asset type. Blocks are produced by RandomARQ proof of work and Zarcanum proof of stake. There is no premine.

The public site is [privacydatacoin.com](https://privacydatacoin.com/).

## Repositories

| Repository | Role |
| --- | --- |
| [PDC](https://github.com/PrivacyDataCoin-Project/PDC) | Protocol, daemon (`pdcd`), command-line wallet (`simplewallet`), and the desktop application. Default branch: `master`. |
| [pdc_ui](https://github.com/PrivacyDataCoin-Project/pdc_ui) | Wallet interface embedded in the PDC desktop application. Default branch: `master`. |
| [PrivacyDataCoin-Project.github.io](https://github.com/PrivacyDataCoin-Project/PrivacyDataCoin-Project.github.io) | Source of the public website. |

Current software release: [v2.1.0](https://github.com/PrivacyDataCoin-Project/PDC/releases/tag/v2.1.0).

## Lead developer

[ArqTras](https://github.com/ArqTras) leads development of Privacy Data Coin. That account is the only one that can push directly to these repositories. Everyone else contributes through a pull request.

## Build from source

```bash
git clone --recursive https://github.com/PrivacyDataCoin-Project/PDC.git
```

Dependencies and build steps are in the [PDC README](https://github.com/PrivacyDataCoin-Project/PDC/blob/master/README.md).
